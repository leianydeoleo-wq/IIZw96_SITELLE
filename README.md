# IIZw96_SITELLE 
# Welcome!


I'm a student researcher working on extragalactic astronomy.  This is a collection of computational astrophysics workflows developed through independent work. These repositories show how I approach astronomical data retrieval, analysis, visualization, and scientific interpretation using Python and related tools.

This project involves a multi wavelength analysis of the luminous infrared galaxy (LIRG) IIZw96 using the Imaging Fourier
Transform Spectrometer for the Study of Emission Lines (or SITELLE for its acronym in french) mounted at the Canada-Hawaii-France Telescope. I used python and its science packages to develop workflows for data calibration, spectral fitting, extinction corrected star formation maps and diagnostics for classification of ionization mechanisms across the merger.
